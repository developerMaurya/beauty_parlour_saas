# Frontend Architecture Blueprint

## Architectural Patterns
- **Build Tool**: Vite for ultra-fast HMR and optimized production bundles.
- **Framework**: React.js with functional components and modern React Hooks.
- **Routing**: React Router with role-guarded route trees and lazy-loaded modules.
- **State Management**: Context API / lightweight modular store for auth session, active tenant theme, and global notifications.
- **Styling**: Modern, responsive design system with support for dynamic CSS variables enabling instant tenant white-label theming.
