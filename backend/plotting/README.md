# 🏗️ Real Estate & Colony Plotting Monolith

This directory contains real estate colony masterplanning & plot sales software:
- **Colony Layout**: Interactive SVG colony layout map with live plot availability status (Available, Token Booked, Sold).
- **Plot Inventory & Pricing**: Dimension, corner plot premium, road width calculation.
- **EMI & Token Booking**: Built-in 12 to 60 months installment plan calculator and token registration.
- **API Endpoints**: `/api/v1/kashi/plotting/*`
