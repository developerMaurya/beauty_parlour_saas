# 🎉 Event Planning & Stage Management Monolith

This directory contains event management software:
- **Event Booking**: Destination weddings, corporate expos, stage productions, artist lineups.
- **Gate Tickets & Access Control**: Live QR pass scanner for instant check-in.
- **Budget & Vendor Ledger**: Audio-visual rentals, floral decor, catering invoices.
- **API Endpoints**: `/api/v1/kashi/events/*`
