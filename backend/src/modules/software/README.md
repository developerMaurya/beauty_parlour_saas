# 💻 Multi-Tenant SaaS Software Suite Monolith

This directory contains cloud software verticals for small and medium enterprises (SMEs):
- **`grocery/`**: Supermarket & retail grocery cloud POS, barcode scanner API, batch expiry tracking, supplier purchase orders.
- **`institute/`**: Computer & vocational training institute ERP, student KYC, batch timetable, fee installments, online exams, PDF certificates.
- **`electronics/`**: Mobile & electronics repair shop ERP, IMEI & serial number registry, job cards, warranty claims.
- **`boutique/`**: Designer boutique & custom tailoring management, customer measurement cards, raw fabric stock, garment dispatch.
- **`controllers/`**: Master software catalog & overview controllers.
- **`routes/`**: Express route slices under `/api/v1/kashi/software/*`.
