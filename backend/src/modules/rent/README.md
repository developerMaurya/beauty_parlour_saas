# 🔑 Rental Properties & Machinery Leasing Monolith

This directory contains asset leasing & rental operations software:
- **Asset Catalog**: Commercial real estate, wedding banquets, earthmovers & JCBs, scaffolding, luxury vehicles.
- **Lease Agreements**: Dynamic digital lease generation with automated security deposit tracking.
- **Rent Collections**: 1-click automated monthly UPI invoice generator with WhatsApp payment link bot.
- **API Endpoints**: `/api/v1/kashi/rent/*`
