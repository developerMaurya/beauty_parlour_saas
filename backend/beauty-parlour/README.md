# 💄 Beauty Parlour & Luxury Salon Modular Monolith

This directory contains the entire, self-contained Beauty Parlour SaaS vertical:
- **`admin/`**: Multi-branch salon administration, staff management, biometric punch-clock, inventory, POS billing, dynamic service catalog, website CMS, CRM & notifications.
- **`staff/`**: Staff portal, live GPS field tracker, appointment queue, doorstep service dispatch, leave management.
- **`student/`**: Beauty academy LMS, student admissions, batch timetable scheduler, exam grading, digital PDF certificate generation.
- **`customer/`**: Customer self-booking portal, order tracking, loyalty wallet, invoice downloads.
- **`guest/`**: Instant guest checkout & appointment scheduler.
- **`public/`**: Public salon storefront website, interactive treatments menu, online booking wizard.
- **`superadmin/`**: Platform tenant onboarding, custom domain management, subscription tiers.
- **`controllers/`**: Beauty parlour vertical controllers.
- **`routes/`**: Beauty parlour vertical API route slices.
