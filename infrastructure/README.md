# Infrastructure & Deployment

Containerization, reverse proxying, ingress routing, SSL termination, and orchestration configurations.

## Subdirectories
- `docker/`: Dockerfiles and multi-container Docker Compose definitions.
- `nginx/`: Nginx reverse proxy configurations with dynamic wildcard & custom domain routing.
- `deployment/`: CI/CD pipelines and production deployment manifests.
- `monitoring/`: Health metrics, logging agents, and APM configurations.
- `backups/`: Automated per-tenant and central database backup automation.
